# Repo-Anweisungen

- Alle Änderungen in diesem Repository sollen nach Abschluss einer Aufgabe automatisch committet und nach `origin/master` gepusht werden — ohne separate Rückfrage/Bestätigung für `git add`, `git commit` oder `git push` in diesem Repo.
- Commit-Messages weiterhin aussagekräftig und im bisherigen Stil halten (kurz, Fokus auf das "Warum").
